## Інструменти та бібліотеки 
У проєкті ми використовували:
'yfinance' - для отримання історичних ринкових даних (ціна відкриття, закриття, обсяги торгів)
'pandas' - для структуризації даних у DataFrame, їх очищення та розрахунку ковзних середніх
'matplotlib' - для візуалізації динаміки ціни та відображення точок входу/виходу з позиції

## Опис аналізу:

Ми реалізували алгоритм **Moving Average Crossover** з періодами 20 та 50 днів, отримали дані про очікуваний прибуток та зробили висновок, у якому свідчиться про ефективність використання такої моделі інвестування у випадку акцій компанії Tesla.

## Висновок 

Попри помітний ріст акцій компанії, модель SMA20/SMA50 виявилась збитковою. Протестувавши стратегію на більш стабільних акціях Apple та золоті, ми зробили висновок, що модель найкраще модель працює з продуктами з малою волатильністю.
